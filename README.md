# chezdot

This repository contains my personal dotfiles, managed with [chezmoi](https://www.chezmoi.io/).
It provides a reproducible setup for my development environment on Linux.

## Features

- Shell configuration (zsh) with [antidote](https://getantidote.github.io/) for plugin management
- Neovim configuration using [LazyVim](https://www.lazyvim.org/) for enhanced editing experience
- Custom prompt theme using [powerlevel10k](https://github.com/romkatv/powerlevel10k)

## Getting Started

1. **Install chezmoi**  
   [Follow the official installation guide](https://www.chezmoi.io/install/)

2. **Initialize and apply dotfiles**  

   ```sh
   chezmoi init --apply https://github.com/AtifChy/chezdot.git
   ```
